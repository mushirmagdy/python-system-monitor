# python-system-monitor
Python System Monitoring Tool

Project Overview

This project is a Python-based system monitoring tool designed to check basic Linux system resources and identify potential problems.

Project Goals

- Monitor CPU usage.
- Monitor memory usage.
- Check disk space.
- Display warnings when resource usage exceeds defined thresholds.
- Record monitoring results and errors in log files.
- Include automated tests and documentation.

Technologies

- Python
- Linux
- Git and GitHub
- Python testing tools

Project Status

In development. Testing on a Linux environment is pending.

Learning Objectives

This project demonstrates practical Python programming, system monitoring, error handling, logging, and automated testing.

Future Improvements

- Add configurable warning thresholds.
- Generate structured monitoring reports.
- Integrate the tool into a DevOps workflow.
